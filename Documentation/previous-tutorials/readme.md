# Previous tutorials

These feature-by-feature lessons are preserved as historical material. They are
outside the DocC catalog and are not part of the current learning course.

The current course teaches scenes, components and systems, player input,
collision-aware movement, and levels. Advanced topics are explained in task guides.
Their complete code examples remain in the DocC Resources directory and are still
compiled by the documentation checker. Old public tutorial URLs redirect to the
corresponding guide; DemoBots redirects to its sample-app page.

See [[../../readme]] for the current documentation entry point and [[../../releasing]]
for the catalog structure and static-site publishing process.
